# Speaker Speech (Спич) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eagerly generate per-slide theses + oral speech during deck generate, edit them in a DeckView modal, export speech as PDF, and embed notes into PPTX export.

**Architecture:** After compose/build, a SpeechAgent (`generateObject`) writes `speech.json` in the deck workDir. API exposes GET/PUT/regenerate + speech-pdf. DeckView modal edits with debounce save. PPTX builder gains optional notes slides; export cache considers `speech.json` mtime.

**Tech Stack:** Vitest, Zod, AI SDK `generateObject`, Playwright Chromium (existing), Hono, React + Vite (`apps/web`).

**Spec:** `docs/superpowers/specs/2026-10-07-speech-design.md`

## Global Constraints

- Eager generation in `generate` pipeline (not lazy-on-open)
- Speech PDF required; Word / `.txt` out of scope
- PPTX speaker notes when `speech.json` exists
- No Slidev presenter / «пульт» notes in MVP
- SpeechAgent failure must not fail the deck (`ready` without `speech.json`)
- TDD: failing test before production code each task
- Do not commit unless user asks
- Russian UI copy as in spec/mockup

- [ ] **Step 3: Implement `speech.ts`**

```ts
import { z } from "zod";

export const SPEECH_JSON = "speech.json";

const nonEmpty = z.string().trim().min(1);

export const SpeechSlide = z.object({
  index: z.number().int().positive(),
  heading: z.string(),
  theses: nonEmpty,
  speech: nonEmpty,
});

export const SpeechDoc = z.object({
  slides: z.array(SpeechSlide).min(1),
});

export type SpeechSlideT = z.infer<typeof SpeechSlide>;
export type SpeechDocT = z.infer<typeof SpeechDoc>;

export function parseSpeechJson(raw: string): SpeechDocT {
  return SpeechDoc.parse(JSON.parse(raw));
}

export function notesTextForSlide(slide: { theses: string; speech: string }): string {
  return `${slide.theses.trim()}\n\n${slide.speech.trim()}`;
}

export function speechUserPrompt(opts: {
  title: string;
  locale: string;
  outlineJson: string;
  slidesMd: string;
}): string {
  return [
    `Напиши спич докладчика для презентации «${opts.title}».`,
    `Язык: ${opts.locale === "en" ? "English" : "русский"}.`,
    `На каждый слайд из outline:`,
    `- theses: шпаргалка, по одной короткой строке на тезис (\\n между строками);`,
    `- speech: полный устный текст, связная речь, не копипаст буллетов слайда;`,
    `- index: 1-based по порядку outline;`,
    `- heading: заголовок слайда из outline.`,
    `Число слайдов в ответе = число слайдов в outline.`,
    ``,
    `Outline JSON:`,
    opts.outlineJson,
    ``,
    `slides.md (справочно):`,
    opts.slidesMd.slice(0, 12000),
  ].join("\n");
}

export function speechSystemPrompt(): string {
  return [
    "Ты помощник докладчика Pokazo.",
    "Пишешь тезисы (шпаргалка) и полный устный спич по слайдам.",
    "Тезисы короткие; спич — как говорят вслух, без markdown-разметки.",
    "Ответ строго по схеме JSON.",
  ].join(" ");
}
```
