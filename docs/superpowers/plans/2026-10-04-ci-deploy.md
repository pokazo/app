# CI blue-green deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Spec: `docs/deploy.md`.

**Goal:** Push to `main` собирает образы в GHCR и без простоя выкатывает web на `91.207.75.72`, api на `80.87.196.33`.

**Architecture:** Два слота Docker + nginx reload. Actions SSH. Docs-only коммиты не деплоят.

**Tech Stack:** GitHub Actions, GHCR, Docker, nginx, `deploy/switch.sh`.

## Global Constraints

- No scp of files from a laptop as the release path.
- Idle slot must pass health before nginx switch.
- Path filters from `docs/deploy.md`.

---

### Task 1: Dockerfiles and compose slots

**Files:** Create `apps/web/Dockerfile` (nginx+dist), `apps/api/Dockerfile`, `deploy/landing/compose.yml`, `deploy/api/compose.yml`, `deploy/switch.sh`

- [ ] Web image: `vite build` → `nginx:alpine`, listen 80 inside, health `/`.
- [ ] API image: Node, `GET /api/health`.
- [ ] Compose: services `a` and `b` with ports 18080/18081, shared postgres/redis only on api host.

### Task 2: switch.sh

- [ ] Read `/etc/pokazo/active-slot`, start idle, wait health, `nginx -s reload`, stop old.
- [ ] Exit non-zero if health fails; do not rewrite active-slot.

### Task 3: GitHub Actions

**Files:** Create `.github/workflows/deploy.yml`

- [ ] `on.push.branches: [main, master]`
- [ ] jobs: `test` → `build-web` / `build-api` (paths) → `deploy-landing` / `deploy-api`
- [ ] `docs/**` excluded via paths-ignore on deploy jobs
- [ ] `concurrency` per job

### Task 4: Server bootstrap (once, not every commit)

- [ ] DNS `api.pokazo.ru` → `80.87.196.33`
- [ ] Install docker+nginx, deploy user, GHCR login on both hosts
- [ ] Secrets in GitHub Environments `landing` and `api`

### Task 5: Verify zero-downtime

- [ ] Two successive deploys; curl `https://pokazo.ru` and `https://api.pokazo.ru/api/health` every 1s during switch; no stretch of 502 > 1 probe.
