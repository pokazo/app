# Дизайн-система Pokazo

> Проверено: 2026-10-04 · источники: [Presentia](https://www.presentia.ai/) (layout), [wordstat-top-queries.md](./wordstat-top-queries.md), бренд Показо

## Вердикт

Визуальный язык — **светлый фиолетовый SaaS как Presentia**: белый фон, лавандовый wash, крупная карточка-промпт, CTA pill. Копирайт и SEO — Wordstat, не английский Presentia. Имя, логотип и обещание PPTX Presentia не копируем.

**С чего начать:** токены `--pk-*` в `apps/web/src/styles/tokens.css`.

## Принципы

| # | Правило |
|---|---------|
| 1 | Один экран — одно действие (тема / вход / показ). |
| 2 | Герой: H1 Wordstat + textarea + «Создать» в карточке. |
| 3 | CTA фиолетовый `#6D28D9`. Яндекс ID — официальный красный. |
| 4 | Без нейро-частиц и без «Export to PowerPoint» в герое. |
| 5 | Интерфейс на «ты». H1 из Wordstat, не «Effortlessly Generate». |

## Токены цвета

| Токен | Hex | Роль |
|-------|-----|------|
| `--pk-paper` | `#FFFFFF` | фон |
| `--pk-paper-2` | `#F7F5FB` | полосы секций |
| `--pk-ink` | `#0F1220` | текст |
| `--pk-ink-muted` | `#5B6178` | вторичный |
| `--pk-line` | `#E6E1F0` | бордеры |
| `--pk-spot` | `#6D28D9` | CTA, акцент «нейросеть» |
| `--pk-spot-hover` | `#5B21B6` | hover CTA |
| `--pk-spot-soft` | `#EFE8FF` | chips |
| `--pk-danger` | `#B42318` | ошибки |
| `--pk-ok` | `#2F6B4F` | успех |

Яндекс-кнопка: `#FC3F1D`, не `--pk-spot`.

## Типографика

| Роль | Шрифт | Вес |
|------|--------|-----|
| Логотип | Иконка стопки слайдов (`favicon.svg`) | — |
| H1 / H2 / UI | Golos Text | 400/500/600 |
| Акцент в H1 | Golos italic + `--pk-spot` на «Нейросеть» | 600 |

`html { font-family: "Golos Text", system-ui, sans-serif }`.

## Сетка

Контент max-width **1120px**. Карточка промпта max **720px**. Радиусы: 10px инпуты, 16px карточки, pill кнопки. Фокус: 2px `--pk-spot`.

## Компоненты MVP

Те же: `PkHeader`, `PkButton`, `PkInput`, `PkSlideFrame` (превью 16:9 в сетке), `PkAuthCard`, статус одной строкой.

## Лендинг (каркас)

```
[ Header логотип + Войти ]
[ Hero: H1 Wordstat + prompt-card ]
[ 3 шага с кружками ]
[ Сетка статичных превью ]
[ Урок / Доклад / Школа / Студенты / Бизнес ]
[ FAQ ]
[ Фиолетовый баннер «Создать презентацию» ]
[ Footer юр. ]
```

## Не брать

- Бренд Presentia, счётчик 143k, тарифы $0.99.
- PPTX как главное обещание героя.
- Inter как единственный шрифт (кириллица — Golos).
- Gamma в title.
