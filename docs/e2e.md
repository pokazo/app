## Чеклист

| ID | Ожидание | Как |
|----|----------|-----|
| A | Лендинг: H1 «Нейросеть для презентаций», форма, «Войти» | `https://pokazo.ru/` |
| B | `/login`: Яндекс, почта, согласие | `/login` |
| C | OTP: письмо → код → `/app` | почта + форма кода |
| D | `/app` без сессии → редирект на логин | инкогнито или после выхода |
| E | `/app` со сессией: список презентаций, «Смотреть» у готовой | `/app` |
| F | `/view/:id`: слева миниатюры-список, по центру выбранный слайд крупно; клик по другой миниатюре меняет центр; счётчик страниц | главная фича этой итерации |
| G | «Выйти» убирает сессию | кнопка в шапке |
| H | Логотип в шапке — иконка стопки слайдов, ведёт на `/` | header |

E0: выпадающих меню нет. Escape/клик-вне — n/a.
