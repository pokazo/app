# Колоды за сегодня

Триггеры: «кто сегодня делал презентации», «кроме меня», «покажи резалтс», «дай ссылку», `/today-decks`.

## Ссылка

Открывать колоду только так:

`https://api.pokazo.ru/p/{id}/`

Слайды листаются стрелками внизу справа и клавишами ← →. Адрес сам уходит на `/1`, дальше на `/2` и так далее.

Не давать:

- `https://pokazo.ru/view/{id}` — большой слайд по страницам не листается
- `?embedded` и голый `/p/{id}/1` как единственную ссылку — это один кадр, без пролистывания

Ссылку давать только если `status` = `ready` или `preview`. Иначе назвать статус и не подставлять `/view`.
